## Rodando localmente

### Pré-requisitos

* Node.js
* npm

### Instalação

Clone o repositório:

```bash
git clone https://github.com/Gu1san/portfolio-site
```

Entre na pasta do projeto:

```bash
cd portfolio-site
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:3000
```

## Build

Para gerar a versão de produção:

```bash
npm run build
```

Para executar a aplicação em produção localmente:

```bash
npm start
```
